# LaTeX version of the risk-advice paper

`paper-risk-advice.tex` is generated from `docs/paper-risk-advice-draft.md` with pandoc
(figures switched to the PDF versions in `figures/`). Build with
`cd writeups && pdflatex paper-risk-advice.tex` (run twice). Edits made directly to the .tex
will be lost if it is regenerated from the Markdown.
