# LLM Revealed Preferences

Structural estimation of economic preference primitives (risk aversion, loss aversion, reference dependence) from elicited LLM choices.

Summer OJT Practicum (Course 1012), Pardee RAND, Jun 29 - Sep 4 2026.

- `proposal/` - LaTeX research proposal
- `src/` - elicitation harness
- `data/` - elicited choice datasets (CSV)
- `analysis/` - estimation notebooks/scripts
- `docs/` - design docs, lit notes
